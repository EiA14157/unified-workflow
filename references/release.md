# Release and services

- Confirm the exact target, access, desired audience, input artifact, and whether the request covers a draft, staging, or going live. Keep unrelated configuration and permissions unchanged.
- Check prerequisites against the selected platform's official guidance when needed. If a named tool or doc is unavailable, use a supported equivalent that preserves the same destination and authorization, or report the blocker.
- Match the published artifact to the verified revision or version. Open the real destination and check the requested result there; dashboard status alone does not prove the public link works. If publishing is pending, name what still needs confirmation and report it as pending.
